# LIBERO — 湯沸かし訓練

学園祭のコーヒー店舗で、最大5台の電気ケトルを管理するリベロ役の3Dトレーニングゲームです。難易度は `EASY`（2台・3人）、`NORMAL`（3台・4人）、`HARD`（4台・5人）、`DEATH MARCH`（5台・6人）の4段階です。さらに `MORNING`、`LUNCH`、`AFTERNOON`、`CLOSING` の時間帯を選択でき、注文間隔と3D空間の光色が変化します。

8個の共有コーヒーポットのキュー内から先頭の空ポットを自動取得し、900ml・92°C以上のお湯を届けます。キュー先頭に戻り湯入りポットが残っていても提供は継続できます。返却ポットには少し冷めた湯が400〜500ml残るため、戻り湯回収はキュー先頭に対して行います。

コーヒーポットの3Dモデルは、鏡面ステンレスの縦長ボディ、ドーム形のフタ、極細のS字注ぎ口、大きな金属製ループハンドルを持つドリップポット形状です。

給水はボタンまたは `F` キーを押している間、毎秒約250mlの速さで進みます。加熱出力は一定で、温度上昇速度はケトル内の水量に反比例します。

加熱停止後の電気ケトルは、毎秒約0.25°Cの割合で緩やかに冷めます。

注文待ちは `ON TIME`、`DELAYED`、`CRITICAL`、`OVERDUE` の4段階です。難易度ごとの基準時間は以下のとおりで、注文ごとに全区間へ±10%のランダム補正が入ります。時間切れの注文は消えず、`OVERDUE` のまま提供されるまで保持されます。

| 難易度 | ON TIME | DELAYED | CRITICAL | OVERDUE到達 |
| --- | ---: | ---: | ---: | ---: |
| EASY | 26秒 | 18秒 | 12秒 | 56秒 |
| NORMAL | 20秒 | 14秒 | 10秒 | 44秒 |
| HARD | 15秒 | 11秒 | 8秒 | 34秒 |
| DEATH MARCH | 11秒 | 8秒 | 6秒 | 25秒 |

画面上の達成度は、最初の注文が発生してから、時間超過の注文が一件もない状態で稼働できた時間の割合です。最終達成度95%以上でランクS、85%以上でA、70%以上でBとなります。

## ローカル実行

ES Modulesを利用するため、任意の静的HTTPサーバーで配信してください。

```bash
python3 -m http.server 8080
```

## ビルド

```bash
npm run build
```
