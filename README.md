# LIBERO — 湯沸かし訓練

学園祭のコーヒー店舗で、5台の電気ケトルを管理するリベロ役の3Dトレーニングゲームです。ケトルは作業台右側にM字で配置されています。6人のドリッパーから届く要求には、8個の共有コーヒーポットをFIFOキューの先頭から使用し、900ml・92°C以上のお湯を届けます。返却ポットには少し冷めた湯が400〜500ml残るため、キュー先頭に来た時点で選択中の電気ケトルへ戻します。

給水はボタンまたは `F` キーを押している間、毎秒約250mlの速さで進みます。加熱出力は一定で、温度上昇速度はケトル内の水量に反比例します。

加熱停止後の電気ケトルは、毎秒約0.25°Cの割合で緩やかに冷めます。

ドリッパーごとの注文待ち時間は35〜50秒のランダムです。時間切れの注文は消えず、時間超過状態のまま提供されるまで保持されます。

## ローカル実行

ES Modulesを利用するため、任意の静的HTTPサーバーで配信してください。

```bash
python3 -m http.server 8080
```

## ビルド

```bash
npm run build
```
