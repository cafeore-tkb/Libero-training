# LIBERO — 湯沸かし訓練

学園祭のコーヒー店舗で、最大5台の電気ケトルを管理するリベロ役の3Dトレーニングゲームです。難易度は `EASY`（2台・3人）、`NORMAL`（3台・4人）、`HARD`（4台・5人）、`DEATH MARCH`（5台・6人）の4段階です。さらに `MORNING`、`LUNCH`、`AFTERNOON`、`CLOSING` の時間帯と、90秒・120秒・150秒のプレイ時間を選択できます。時間帯によって注文間隔と3D空間の光色が変化します。

開始画面は `DIFFICULTY`、`TIME SLOT`、`PLAY TIME`、`DESCRIPTION` の2列×2行で構成し、設定と操作説明をスクロールせず確認できるようにしています。

8個の共有コーヒーポットのキュー内から先頭の空ポットを自動取得し、92°C以上のお湯を合計900ml届けます。ケトルに900mlなくても、その時点で入っている分だけ注湯できます。部分注湯中のポットはドリッパーごとに保持され、同じケトルまたは別のケトルから継ぎ足して900mlに達した時点で注文完了です。戻り湯入りポットが残っていても提供は継続できます。返却ポットには少し冷めた湯が400〜500ml残るため、キュー内で最初の戻り湯入りポットから回収します。空ポットが先にあっても回収できます。選択中のケトルが加熱停止中で空き容量を持てば、入りきる量だけ部分回収できます。残った湯は同じポットに保持され、別のケトルへ続けて戻せます。全量回収した時だけ空ポットとしてキュー末尾へ移動します。

ポットキューは状態ごとに安定整列され、空ポットを左側、注湯途中のポットを中央、戻り湯入りポットを右側に配置します。同じ状態のポット同士では、それまでの順番を維持します。

コーヒーポットの3Dモデルは、鏡面ステンレスの円錐台形ボディ、ドーム形のフタ、極細のS字注ぎ口、大きな金属製ループハンドルを持つドリップポット形状です。

操作キーはJIS配列の左ホームポジションに合わせ、`A` 長押しで給水、`S` で加熱、`D` で戻り湯回収、`F` で注湯です。ケトルは数字キー `1`〜`5` で選択します。給水は毎秒約288mlの速さで進みます。900mlの給水は約3.1秒、22°C・900mlからの加熱は約4.4秒、提供後のポット返却待ちは約6.1秒です。給水・加熱・返却は従来比で一律1.15倍速です。加熱出力は一定で、温度上昇速度はケトル内の水量に反比例します。

加熱停止後の電気ケトルは、毎秒約0.25°Cの割合で緩やかに冷めます。

注文待ちは `ON TIME`、`DELAYED`、`CRITICAL`、`OVERDUE` の4段階です。時間帯ごとの基準時間は以下のとおりで、注文ごとに全区間へ±10%のランダム補正が入ります。時間切れの注文は消えず、`OVERDUE` のまま提供されるまで保持されます。難易度はケトル数とドリッパー数だけを変更します。

| 時間帯 | ON TIME | DELAYED | CRITICAL | OVERDUE到達 |
| --- | ---: | ---: | ---: | ---: |
| MORNING | 39秒 | 27秒 | 18秒 | 84秒 |
| LUNCH | 17秒 | 12秒 | 9秒 | 38秒 |
| AFTERNOON | 30秒 | 21秒 | 15秒 | 66秒 |
| CLOSING | 23秒 | 17秒 | 12秒 | 52秒 |

画面上の達成度は注文単位の評価です。提供時の状態を `ON TIME=100%`、`DELAYED=50%`、`CRITICAL=10%`、`OVERDUE=0%` として平均します。未提供の注文はON TIMEの猶予を過ぎたら0%で評価対象に入ります。猶予中は評価保留とし、終了直前に来た注文でも猶予切れまでは不利に扱いません。評価対象がなければ「未評価」です。提供済みの評価は確定し、待機時間だけで回復することはありません。最終達成度100%（評価対象が全件ON TIME）でランクS、95%以上でA、85%以上でB、それ未満はCとなります。ランクは丸め前の値で判定し、結果画面に評価件数・未提供件数・提供時の状態別件数を表示します。

給湯時には、定刻かつ96°C以上で `PERFECT`、超過直前なら `JUST IN TIME`、最後の超過注文を解消すると `RECOVERY` が表示されます。時間超過前の連続提供でCHAINが育ち、3回で `FLOW!`、5回で `UNSTOPPABLE`、10回ごとに `LEGENDARY` を演出します。時間超過と空焚き・低温での給湯試行でCHAINがリセットされます。演出は達成度や機器性能を変えません。

給湯の軌跡、短い効果音、沸き上がり通知、結果のカウントアップを追加しています。右上の `FX` と `♪` で動きと音を個別に切り替えられ、OSの「視差効果を減らす」設定にも対応します。

## ローカル実行

Three.js 0.170.0 は `vendor/` に同梱しており、起動時に外部CDNへ接続する必要はありません。ライセンスは `vendor/three.LICENSE` にあります。難易度・時間帯・プレイ時間の選択は3D描画の初期化から独立しているため、準備中も選択できます。選択中の設定は3D描画の準備後とシフト開始時に引き継がれます。

ES Modulesを利用するため、任意の静的HTTPサーバーで配信してください。

```bash
python3 -m http.server 3000 --bind 127.0.0.1
```

## ビルド

```bash
npm run build
```
