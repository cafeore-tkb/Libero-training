# LIBERO — 湯沸かし訓練

学園祭のコーヒー店舗で、5台の電気ケトルを管理するリベロ役の3Dトレーニングゲームです。6人のドリッパーから届く要求に合わせ、8個の共有コーヒーポットから空いているものを選び、合計900ml・92°C以上になるように給湯します。返却ポットには少し冷めた湯が400〜500ml残るため、残量と混合後の温度を見ながら継ぎ足します。

## ローカル実行

ES Modulesを利用するため、任意の静的HTTPサーバーで配信してください。

```bash
python3 -m http.server 8080
```

## ビルド

```bash
npm run build
```
