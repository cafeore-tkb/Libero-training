# LIBERO — 湯沸かし訓練

学園祭のコーヒー店舗で、5台の電気ケトルを管理するリベロ役の3Dトレーニングゲームです。6人のドリッパーから届く要求に合わせ、8個の共有コーヒーポットから空いているものを選び、900ml・92°C以上のお湯を届けます。返却ポットには少し冷めた湯が400〜500ml残るため、再使用前に必ず選択中の電気ケトルへ戻します。

給水はボタンまたは `F` キーを押している間だけ進みます。加熱出力は一定で、温度上昇速度はケトル内の水量に反比例します。

## ローカル実行

ES Modulesを利用するため、任意の静的HTTPサーバーで配信してください。

```bash
python3 -m http.server 8080
```

## ビルド

```bash
npm run build
```
